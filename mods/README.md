# Моды WorldSimulator

Мод — папка в `mods/` рядом с игрой (или в `~/.local/share/WorldSimulator/mods/`).
Игра находит её при запуске, мод включается и выключается на странице
**Настройки → Моды**. Установка мода: положить его папку в `mods/` и запустить игру.

Сейчас моды добавляют **силы бога** — кисти на нижней панели в игре (клавиши 1–9,
ЛКМ — применить, `[` `]` или Ctrl+колесо — радиус). Правила симуляции моды не меняют.

```
mods/my_mod/
  mod.json            манифест (обязателен)
  scripts/*.lua       скрипты сил
```

## mod.json

```json
{
  "id": "my_mod",            // a-z, 0-9, _ ; до 32 символов, уникален
  "name": "Мой мод",
  "version": "1.0",
  "author": "я",
  "description": "что делает",
  "api_version": 1,          // должен совпадать с версией API игры (сейчас 1)
  "powers": [ ... ]
}
```

Игра показывает мод, даже если он не загрузился, — ошибка видна в списке модов.

### Силы (`powers`)

Общие поля: `id` (a-z0-9_), `name`, `description`, `radius`, `min_radius`, `max_radius`,
`interval`. Итоговый id силы — `<id мода>.<id силы>`.

`interval`: `0` — применять каждый шаг симуляции, пока зажата кнопка; число > 0 — раз в столько секунд;
`-1` — один раз на нажатие.

| `type`      | Что делает                                              | Поля                         |
|-------------|---------------------------------------------------------|------------------------------|
| `raise`     | поднимает рельеф                                        | `rate` (единиц высоты/с)     |
| `lower`     | опускает рельеф                                         | `rate`                       |
| `flatten`   | выравнивает по высоте точки нажатия                     | `rate`                       |
| `spawn`     | создаёт существ; черты задают вид                       | `traits`, `interval`         |
| `erase`     | убирает существ, постройки и ягодные кусты в круге      | —                            |
| `bush`      | сажает ягодные кусты (пока кнопка зажата)               | `berry` (вид ягод; без него -- по биому под курсором), `interval` |

Виды ягод (`berry`): `raspberry` (малина), `blueberry` (черника), `blackberry` (ежевика), `cloudberry` (морошка),
`tropical` (тропическая ягода), `cactus` (колючий плод) и пять ядовитых с разным действием: `nightshade` (волчья ягода --
смерть, под цвет ежевики), `baneberry` (вороний глаз -- рвота и понос, белая), `buckthorn` (крушина -- понос, под цвет черники),
`honeysuckle` (жимолость -- рвота, под цвет малины), `henbane` (белена -- галлюцинации, под цвет морошки). Виды различаются
сытностью, скоростью отрастания, цветом и действием; существа запоминают вкус по внешнему виду и обходят те, что их отравили.
| `script`    | свой код на Lua                                         | `script` (путь в папке мода) |

Черты (`traits`, значения от -1 до 1): `speed`, `size`, `metabolism`, `lifespan`, `fertility`,
`plasticity`, `boldness`, `sociability`, `bondStrength`, `envy`, `territorial`, `curiosity`, `empathy`.
Мозг у созданного существа всегда случайный.

## Скрипты на Lua

Скрипт возвращает функцию `apply(ctx, p)` или таблицу с полем `apply`.

`p` — вызов: `p.x`, `p.z` (точка под курсором), `p.radius` (радиус кисти), `p.dt` (секунды), `p.first`
(`true` на первом вызове после нажатия).

`ctx` — рука бога (вызываются через двоеточие):

| Вызов                               | Результат                                              |
|-------------------------------------|--------------------------------------------------------|
| `ctx:height(x, z)`                  | высота рельефа                                         |
| `ctx:raise(x, z, radius, amount)`   | прибавить высоту (в центре `amount`, к краю спадает)   |
| `ctx:flatten(x, z, radius, h, rate)`| подтянуть к высоте `h`, `rate` 0..1                    |
| `ctx:spawn(x, z [, traits])`        | создать существо, `true` если получилось               |
| `ctx:erase(x, z, radius)`           | убрать существ, вернуть сколько                        |
| `ctx:count(x, z, radius)`           | сколько существ в круге                                |
| `ctx:boulder(x, z, radius)`         | сбросить валун: падает, катится, давит существ и постройки, оставляет кратер; `true` если получилось |
| `ctx:build(x, z [, yaw])`           | дом на суше (площадка выравнивается); `true`, если место подошло |
| `ctx:erase_buildings(x, z, radius)` | убрать постройки, вернуть сколько                      |
| `ctx:bush(x, z [, berry])`          | посадить ягодный куст (вид -- id из списка выше, без него -- по биому); `true`, если место подошло |
| `ctx:erase_bushes(x, z, radius)`    | убрать кусты, вернуть сколько                          |
| `ctx:sound(name [, x, z [, vol]])`  | сыграть звук в точке: `thud`, `pop`, `whoosh`, `zap`, `chime`, `knock`; `true`, если игра его знает |
| `ctx:log(text)` / `print(...)`      | вывод в лог игры                                       |

Доступны `math`, `string`, `table`, `utf8` и базовые функции (`pairs`, `type`, `assert`...).
**Нет** `io`, `os`, `require`, `load`, `dofile`, `debug` — мод не читает файлы и не запускает программы.

Ограничения: память мода — 32 МБ; на один вызов силы — около 4 млн инструкций (бесконечный цикл
оборвётся); числа в `ctx` обрезаются до разумных пределов. Ошибка в скрипте отключает **только эту силу** и
показывается на странице «Моды» — игра продолжает работать.

Образец: [`example_gods`](example_gods/) — сила из данных (`hill`, `giant`) и две силы на Lua.
